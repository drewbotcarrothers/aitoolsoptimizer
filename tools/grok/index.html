Grok review

xAI's AI assistant for chat, real-time answers and image and video creation, sold through The X Subscription.

freemium⏱ 4 min readChecked October 16, 2026By Andrew
Visit Grok → Official website

⚡ Quick verdict

Grok's biggest change is commercial: it's now sold through The X Subscription, which bundles Grok, Cursor and X Premium benefits under one shared usage pool. Plus at $8 a month is one of the cheapest paid AI assistant plans, and Premium at $30 adds 4x usage and Grok Bot. It's especially attractive if you also code in Cursor or use X; otherwise compare it with ChatGPT, Claude and Gemini.

Key takeaways

  • Free tier with limited usage; paid plans via The X Subscription.
  • Plus $8/mo ($80/yr), Premium $30/mo ($300/yr), Super $100/mo ($1,000/yr), Ultra $200/mo ($2,000/yr).
  • Usage scales 4x (Premium), 15x (Super) and 50x (Ultra) relative to Plus.
  • One shared usage pool covers Grok models across Grok and Cursor, plus Grok Bot on Premium and above.
  • Team seats on Premium ($30), Super ($100) and Ultra ($200), with mixed tiers allowed.

What Grok is

Grok is the AI assistant built by xAI. You can use it at grok.com, in its mobile apps and directly inside X, where it can draw on real-time conversation and trends. Grok answers questions, writes and edits, helps with research and code, and creates images and video through Grok Imagine.

Paid Grok access is now sold through The X Subscription, which “brings together Grok, Cursor and X.” Paid individual plans include X Premium benefits when you connect your X account, and one shared usage pool covers Grok models across Grok and Cursor.

Key features

Chat and research

General-purpose assistant for questions, writing, analysis and planning.

Grok Imagine

Generate images and video from prompts.

X integration

Use Grok inside X for context on posts and trends.

Shared usage with Cursor

Included usage covers Grok models in Cursor; third-party models in Cursor use additional credits.

Grok Bot

Included on Premium, Super and Ultra, drawing from the same weekly usage pool.

Best use cases

  • News and trends: ask Grok to explain what’s happening in a conversation on X.
  • Writing: draft posts, emails and summaries.
  • Creative work: generate images and short videos with Grok Imagine.
  • Developers: use one plan for Grok and Cursor coding.

How to get started

  1. Go to grok.com or open Grok in X and sign in.
  2. Try the free tier with a few everyday questions.
  3. Experiment with Grok Imagine for images.
  4. Choose a plan at x.ai/pricing if you need more usage.
  5. Connect your X account to get X Premium benefits.

Tips and tricks

  • Pick annual billing to save roughly two months.
  • Watch the shared usage pool if you also code heavily in Cursor.
  • Ask for sources and verify facts on important topics.
  • Set spending caps before enabling top-ups.

Example prompt:

Summarize the main arguments for and against four-day work weeks in five bullets each, then suggest three questions a manager should ask before piloting one.

Pros and cons

👍 Pros

  • Inexpensive Plus tier
  • One subscription covers Grok, Cursor and X benefits
  • Annual billing saves about two months
  • Flexible team seats with mixed tiers
  • Built into X for real-time context

👎 Cons

  • Plan structure is new and can be confusing
  • Plus doesn't include Grok Bot
  • Third-party models in Cursor use extra credits
  • Less value if you don't use X or Cursor

Who should (and shouldn't) use Grok

✅ A good fit if you…

  • Use X regularly
  • Code with Cursor and want one bill
  • Want a low-cost paid assistant

⛔ Look elsewhere if you…

  • Need deep Google or Microsoft app integration (consider Gemini or Microsoft Copilot)
  • Want cited research answers (consider Perplexity)
  • Prefer long-form writing help (consider Claude)

Grok alternatives

  • Claude — Anthropic's AI assistant for writing, analysis, research, coding and long-running work, with Claude Code included on paid plans. (from $17/mo (Pro, annual; $20 monthly); Max from $100)
  • Google Gemini — Google's AI assistant for chat, research, image and video generation, built into Gmail, Docs and Android. (from $4.99/mo (Google AI Plus))
  • Perplexity — AI answer engine with cited sources, Deep Research, the Comet browser and Perplexity Computer. (from $17/mo billed annually (Pro))
  • Cursor — AI coding agent and code editor that builds, tests and ships software from the desktop, CLI, Slack and GitHub. (from $8/mo (Plus); $80/yr)

FAQ

Is Grok free?

Yes. Grok has a free tier with limited usage. Paid plans through The X Subscription increase usage and add features.

How much does Grok cost?

The X Subscription costs $8 per month for Plus, $30 for Premium, $100 for Super and $200 for Ultra, or $80, $300, $1,000 and $2,000 per year. Prices exclude sales tax.

What is The X Subscription?

It's a single subscription that brings together Grok, Cursor and X. Paid individual plans include X Premium benefits when you connect your X account.

Do I have to switch from SuperGrok or X Premium?

No. Existing Cursor, SuperGrok and X Premium plans continue unless you change or cancel them. Switching cancels eligible plans with a prorated refund.

Are there Grok team plans?

Yes. Team seats cost $30 (Premium), $100 (Super) or $200 (Ultra) per seat, with centralized billing, usage analytics and mixed seat tiers. Plus isn't available for teams.
