What Claude is

Claude is the AI assistant built by Anthropic. It’s available on the web at claude.ai, as desktop apps and on iOS and Android, and through extensions like Claude in Chrome and Claude for Microsoft 365 and Outlook. Under the hood it uses Anthropic’s model family (Opus, Sonnet and Haiku, plus newer models listed on its pricing page), with context windows of up to 1M tokens depending on the model.

Claude has grown from a chatbot into a workspace: you can hand off and schedule tasks, create documents, slides and dashboards, connect your tools and, on paid plans, run Claude Code for software work. Anthropic recently merged its Cowork experience into the main Claude app for Pro and Max users.

Key features

Chat, Projects and Artifacts

Organize work into Projects with shared files and instructions (free users get up to 5). Artifacts turn outputs such as code, documents and interactive apps into a side panel you can preview, edit and share.

Research, search and memory

Search the web, run deeper Research tasks and let Claude remember context across conversations.

Connectors and Skills

Connect apps and tools so Claude can read and act on your data, and use Skills to package repeatable workflows.

Create files

Claude Design, Slides and Docs produce real files; code execution lets it analyze spreadsheets and build charts.

Claude Code

Anthropic’s agentic coding tool, included with Pro and Max, works in your terminal, IDE, Slack or the web. See our Claude Code review.

Best use cases

  • Long documents: upload a 100-page contract and ask for obligations, deadlines and risks in a table.
  • Writing: draft a blog post from your notes, then ask Claude to match the tone of a previous article.
  • Analysis: upload a CSV of sales and have Claude build charts and summarize trends.
  • Coding: use Claude Code to fix a bug or write tests in your repository.

How to get started

  1. Sign up free at claude.ai or download the desktop or mobile app.
  2. Create a Project for an ongoing task and add reference files and instructions.
  3. Ask for a concrete deliverable, such as a memo, table or slide outline.
  4. Use Artifacts to preview and refine documents or small apps.
  5. Turn on connectors for tools you use, such as email or docs.
  6. Upgrade to Pro if you hit limits or want Claude Code.

Tips and tricks

  • Put instructions in the Project, so you don’t repeat them every chat.
  • Ask Claude to think through options before recommending one.
  • Paste examples of the style you want; Claude imitates format well.
  • Watch your usage during long sessions and start fresh chats for new topics to save limits.

Example prompts:

Here’s my draft newsletter. Keep my voice, cut it by 30%, make the opening line stronger and list the three changes you made and why.

Analyze the attached survey CSV. Identify the top five themes in open-ended answers with counts and one representative quote each.

FAQ

Is Claude free?

Yes. Claude's free plan lets you chat on web, desktop and mobile, search the web, create files and run code, use memory, connect apps and create Artifacts, with usage limits.

How much does Claude Pro cost?

Claude Pro is $20 per month billed monthly, or $17 per month with the annual discount ($200 billed up front). Prices exclude tax.

What is Claude Max?

Max is for heavy users: Max 5x costs $100 per month and Max 20x costs $200, giving 5x or 20x Pro's usage, higher output limits, priority access and $100 or $200 a month in API credits.

Is Claude Code included with Claude Pro?

Yes. Claude Code is included in Pro and Max plans. Anthropic describes Pro as suited to short coding sprints in small codebases and Max for larger codebases.

Does Anthropic train on my Claude chats?

Anthropic's pricing page lists model training as opt-out on Free, Pro and Max plans, so you can turn it off in your settings.

Does Claude have a team plan?

Yes. The Team plan covers 2 to 150 people with central billing, admin controls and more usage than Pro per standard seat. Enterprise adds SSO, SCIM, audit logs and compliance features.
