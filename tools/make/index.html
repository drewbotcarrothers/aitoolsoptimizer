Make review

⚡ Quick verdict

Make is the most visual of the big automation tools and usually cheaper per action than Zapier. The free plan (1,000 credits a month) is enough to learn, and Core from $9 a month (annual) covers most small businesses. It rewards people who like to see data flow through a scenario, but complex scenarios can burn credits quickly, so estimate usage first.

Key takeaways

  • Free: $0 forever with 1,000 credits per month, no card required.
  • Core: from $9/month billed annually for 10,000 credits per month.
  • Pro: from $16/month annually; Teams: from $29/month annually, each starting at 10,000 credits.
  • Monthly billing costs more than annual; prices rise with the credit tier you choose.
  • Most module actions use 1 credit; some AI features use more. Routers and error handlers are free.

What Make is

Make (formerly Integromat, now part of Celonis) is an AI automation platform. You build automated workflows, called scenarios, and AI agents on a visual canvas, connect them to the apps and data you already use, and watch data move from module to module. A scenario typically triggers when something happens in one app—say a new row in Google Sheets—then processes the data and acts in other apps.

Make connects to 3,500+ apps out of the box and can call any API, so it’s popular with operations, marketing and RevOps teams who need more control than simple two-step automations offer.

Key features

Visual scenario builder

Drag modules onto a canvas and link them. Routers branch logic, iterators and aggregators handle lists, and filters control what passes through.

AI agents and AI modules

Build AI agents and add AI steps to scenarios. Since November 2025, custom AI provider connections are available on all paid plans.

Integrations and APIs

3,500+ prebuilt apps, plus HTTP and webhook modules for anything with an API.

Error handling

Rollback, Break, Resume, Commit and Ignore handlers keep scenarios robust—and they don’t consume credits.

Scheduling and logs

Run scenarios on a schedule or instantly via webhooks, with execution logs to debug.

Best use cases

  • Sales ops: route new leads from forms to CRM and Slack with enrichment.
  • Marketing: turn RSS items into AI-drafted social posts for review.
  • Finance: sync invoices between billing tools and spreadsheets.
  • Support: classify incoming emails with AI and create tickets.

How to get started

  1. Sign up free at make.com.
  2. Start from a template or create a new scenario.
  3. Add a trigger module, then actions, and map fields.
  4. Run once to test and inspect each module’s output.
  5. Schedule it and watch credit usage in the first week.

Tips and tricks

  • Filter early so later modules don’t burn credits.
  • Use aggregators to batch rows into one action.
  • Add error handlers to avoid silent failures.
  • Use webhooks instead of frequent polling.

Example scenario brief:

When a Typeform response arrives, use AI to score the lead 1-5, add it to HubSpot, and post high scores to #sales in Slack.

Pros and cons

👍 Pros

  • Very visual drag-and-drop builder
  • Generous free plan with no time limit
  • Low starting price per credit
  • Handles complex branching and data transformation
  • Connects any API

👎 Cons

  • Credit usage is harder to predict than flat pricing
  • Steeper learning curve than Zapier
  • Scenarios stop when credits run out
  • Monthly prices are higher than headline annual prices

Who should (and shouldn't) use Make

✅ A good fit if you…

  • Build multi-step automations with branching
  • Want to keep automation costs low
  • Like visual, flowchart-style tools

⛔ Look elsewhere if you…

  • Need self-hosting (consider n8n)
  • Want the simplest possible setup (consider Zapier)
  • Need an autonomous general agent (consider Manus or Lindy)

Make alternatives

  • Zapier — No-code automation across 9,000+ apps, with AI agents, Copilot, MCP, Tables and Forms. (from $19.99/mo billed annually (Professional))
  • n8n — Fair-code workflow automation with AI agents—self-host it or use n8n Cloud. (from €20/mo billed annually (Starter, 2.5K executions))
  • Lindy — AI teammate that plugs into your tools, learns how you work and handles real tasks across inbox, sales, marketing and ops. (from $49.99/mo for 5,000 credits (Team))
  • Relevance AI — Build an AI workforce of agents for go-to-market and operations work—no code required. (from $19/mo billed annually (Pro))
  • Manus — General-purpose AI agent that researches, builds websites and slides, and runs scheduled tasks using credits. (from $20/mo for 4,000 credits (Pro))

FAQ

Is Make free?

Yes. The Free plan includes 1,000 credits per month with no time limit and no credit card required.

How much does Make cost?

On Make's own comparison page, Core starts at $9/month, Pro at $16 and Teams at $29, each starting at 10,000 credits per month, with annual billing. Monthly billing is higher, and prices increase with larger credit tiers. Enterprise is custom.

What is a credit in Make?

Credits are now the billing unit in Make. Each action a module performs, such as reading, searching or creating data, usually uses 1 credit; some AI features use more. Routers and error-handler modules don't count.

What happens if I run out of credits?

Scenarios pause until credits are added. Make notifies you at 75% and 90%, queues incoming webhooks, and lets you buy extra credits in bundles or turn on auto-purchasing on Core, Pro and Teams.

How many apps does Make connect to?

Make connects to 3,500+ apps, and anything with an API can be added as a custom integration.

Make or Zapier?

Make is more visual and usually cheaper per action; Zapier is simpler to set up and has more app integrations. See our Zapier review.
