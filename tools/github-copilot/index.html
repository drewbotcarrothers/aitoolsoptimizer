Overview

AI coding assistant integrated into VS Code, JetBrains and GitHub.

Key features

  • Completions
  • Chat
  • Agent mode
  • Multiple models
  • Free for verified teachers/OSS maintainers

Best use cases

  • Code completion
  • Chat about code
  • Coding agent for PRs
  • Code review

Pricing

Freemium. From $10 (Pro) (USD).

Pros and cons

👍 Pros

  • Works in popular editors
  • Good autocomplete
  • Chat about your codebase

👎 Cons

  • Suggestions need review
  • Best features on paid plans

GitHub Copilot alternatives

  • Cursor — AI coding agent and code editor that builds, tests and ships software from the desktop, CLI, Slack and GitHub. (from $8/mo (Plus); $80/yr)

Sources

This is an editorial review based on research of official GitHub Copilot pages and documentation, not hands-on benchmark testing. Prices are in USD and were checked on October 15, 2026; vendors change plans often, so confirm on the official pricing page before buying.
