What Mistral Vibe is

Vibe is Mistral AI’s chat assistant and agent for work and code. It merges two products: Vibe for work, the assistant formerly known as Le Chat, and Vibe for code, Mistral’s coding agent. Mistral describes it as “your AI agent for long-horizon tasks, fluent in your knowledge and tools”: describe the outcome and Vibe plans, drafts and delivers finished work.

Mistral is a Paris-based AI company, and Vibe stands out for deployment flexibility—enterprises can run it on-premises or in a private cloud with full data residency.

Key features

Work agent

Get briefed on what you missed across email, chat, calendar and internal knowledge; analyze uploaded spreadsheets or connected databases; and compile sourced research from the web and internal docs.

Deliverables

Generate PDFs, board decks, strategic briefs, RFP responses, PRDs and reports, plus spreadsheets and slides on Pro.

Automations

Route data across tools, trigger actions and run multi-step processes with human checkpoints. Package workflows into reusable agents or run them on a trigger.

Vibe for code

Scaffold multi-file features with tests and docs, generate tests that match your patterns, migrate legacy codebases and bulk-update dependencies. Use it from the CLI, in VS Code, JetBrains or Zed via ACP, or as remote agents.

Connectors

100+ tools including email, calendar, Slack, GitHub and Jira, with full MCP compatibility.

Best use cases

  • Consultants: turn research into a sourced brief and deck.

How to get started

  1. Sign up at mistral.ai and open Vibe on the web or mobile.
  2. Try a research or writing task on Free.
  3. Connect tools such as your calendar or GitHub.
  4. Install the CLI to try Vibe for code.
  5. Upgrade to Pro for agents and all-day coding.

Tips and tricks

  • Describe the finished deliverable and its audience.
  • Use project folders to keep context together.
  • Create Skills for repeatable instructions.
  • Add checkpoints before agents take actions.

Example prompt:

Using my calendar and inbox from this week, write a one-page brief of decisions made, open questions, and who owes what, then draft a Slack update for my team.

FAQ

What happened to Le Chat?

Le Chat is now Vibe. Mistral says all your conversations, settings and plans carry over. Vibe combines the chat assistant (Vibe for work) and the coding agent (Vibe for code).

Is Mistral Vibe free?

Yes. The Free plan gives limited access to Vibe, including the latest models, chat, search, creation and Vibe for code for agentic coding in your terminal.

How much is Vibe Pro?

Pro costs $14.99 per month excluding taxes and is subject to fair-usage limits. Verified students at accredited higher-education institutions can get Pro for $5.99 per month for up to 12 months if they haven't used Vibe or Le Chat before.

How much is the Team plan?

Team is $24.99 per user per month and adds even higher limits, domain name verification and data export.

How do I use Vibe for code?

Install the CLI from your terminal, launch it in VS Code, JetBrains or Zed via ACP, or start coding tasks in Vibe with remote agents and teleport back to the CLI.

Can Vibe be self-hosted?

Enterprise customers can deploy Vibe on-premises, in a private cloud or on Mistral Cloud with full data residency, and fine-tune through Mistral Forge.
