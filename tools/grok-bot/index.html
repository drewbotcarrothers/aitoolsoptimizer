What Grok Bot is

Grok Bot is xAI’s agent product in the Grok family. xAI calls Bots “AI teammates”: you message one the way you would a colleague, give it a task and access to the tools it needs, and it carries out multi-step work across apps and websites. It keeps you updated in the conversation and comes back when something needs your approval.

The main difference from a chat assistant is that each Bot works on a persistent cloud computer with a browser, filesystem and terminal. It uses connectors where they exist and computer use for everything else, so according to xAI it can work in tools that have no clean API, and keep going while your laptop is closed. xAI says Grok Bot started as an internal prototype that teams used for sales outbound, marketing campaigns, office operations and bug fixes.

Key features

A cloud computer that persists

All of your Bots share one cloud computer, including its files, browser sessions and app logins, so handoffs don’t require repeating setup. The docs note that anything on it is available to every Bot you run.

Several Bots in parallel

Create a Bot per job (one on a project, one on outbound, one on systems). Bots can message each other, share context in group chats and pass ownership of a task.

Skills and routines

Walk a Bot through a workflow once and it can save it as a skill and rerun it on a schedule. Bots can also watch for events, such as a Slack thread or a GitHub PR.

Connectors and integrations

Grok Bot supports the same MCP servers, plugins and skills as Cursor, including Gmail, Google Calendar and Google Drive, with multiple accounts per service.

Tag @bot on X

Tag @bot in a post or reply and your main Bot picks it up as a task. This requires a connected X account and isn’t available in every region yet.

Approvals and security

Sensitive actions can go through Auto Review before they run. The cloud computer is encrypted in transit and at rest, with a training opt-out, and Enterprise admins can set DLP, certificates, proxies and network controls.

Best use cases

  • Sales: pull a pipeline list from your CRM, research accounts and leave outreach drafts to approve.
  • Marketing and operations: run multi-step campaigns and admin tasks across several tools.
  • Recurring work: turn a workflow you’ve shown once into a scheduled routine.
  • Developers: gather context from Slack, GitHub and docs, then hand a clean prompt to a Cursor cloud agent.

How to get started

  1. Download Grok Bot for desktop, or from the App Store or Google Play.
  2. Sign in with an account on an eligible plan.
  3. Create your first Bot, give it a name and describe its job.
  4. Grant access to apps as it asks.
  5. Hand it a real task with a clear finish line, then review the result.

Tips and tricks

  • Describe what “done” looks like so the Bot knows when to stop.
  • Turn stable processes into skills once a task works well.
  • Remember the computer is shared between your Bots when you log in to sites.
  • Ask it to check the current source for important decisions instead of relying on memory.

Example first task (adapted from xAI’s docs):

Pull this week’s pipeline review list from our CRM. Skip anyone already in an active sequence. Research the top five accounts, draft outreach in my voice, and leave me drafts to approve by tomorrow morning.

Pros and cons

👍 Pros

  • Works inside real apps and websites, including ones without an API
  • Keeps working while your devices are off
  • Several Bots can coordinate in group chats
  • Included in existing X Subscription and Cursor plans
  • Approval step for sensitive actions

👎 Cons

  • Not on the free tier or the $8 Plus plan
  • Newer product; xAI describes it as in beta at launch
  • Sites can still block automation or need a human step
  • All Bots share one computer, so files and logins are shared between them

Who should (and shouldn't) use Grok Bot

✅ A good fit if you…

  • Want to delegate multi-step work, not just get answers
  • Already pay for The X Subscription or Cursor
  • Run recurring workflows across several tools

⛔ Look elsewhere if you…

  • Only need a chat assistant (consider Grok or ChatGPT)
  • Want a self-hosted, open-source agent (consider OpenClaw or Hermes Agent)
  • Want simple app-to-app automations (consider Zapier)

FAQ

What is Grok Bot?

Grok Bot is xAI's product for AI teammates. Each Bot works on a persistent cloud computer with a browser, filesystem and terminal, takes on multi-step work across apps and websites, and comes back when it needs your approval.

How much does Grok Bot cost?

There's no separate price. xAI's X Subscription docs say Grok Bot is included on Premium ($30/mo), Super ($100/mo) and Ultra ($200/mo), but not Plus. Grok Bot's docs say it's also included with every paid individual Cursor plan and Cursor Teams, or through a linked SuperGrok plan.

Does Grok Bot keep working when my laptop is closed?

Yes. According to the docs, work runs on the cloud computer, so closing the app, laptop or phone doesn't stop a background task or routine.

Which platforms does Grok Bot support?

The desktop app runs on macOS, Windows and Linux, and the mobile app runs on iPhone, iPad and Android.

Is Grok Bot available for businesses?

Yes. xAI says Grok Bot is generally available for Enterprise and for teams on the Teams plan, with admin controls such as DLP, proxies and network controls.
