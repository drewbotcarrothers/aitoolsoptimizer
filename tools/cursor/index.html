What Cursor is

Cursor describes itself as “your coding agent for building ambitious software.” It started as an AI-first fork of the VS Code editor and has grown into a family of interfaces: the desktop editor, an Agents window, a command-line tool, an iOS app, a Slack integration and GitHub pull-request reviews. You can make a targeted edit with a shortcut, chat about your code, or hand off an entire feature to an agent that uses its own computer to build, test and demo the result for your review.

In 2026 Cursor became part of The X Subscription, a single plan covering Grok, Cursor and X. New customers subscribe there; existing customers can stay on legacy Cursor plans.

Key features

Tab, Chat and Agent

Tab predicts your next edits as you type. Chat answers questions about your codebase. Agent mode plans and makes multi-file changes, runs commands and iterates.

Cloud agents

Agents work on their own computers to build, test and demo features end to end, so you review finished work instead of watching each step.

CLI, Slack and GitHub

Run Cursor in the terminal, mention it in Slack to kick off tasks and let it review pull requests on GitHub.

Models and routing

Pick models yourself or let Cursor choose with Cost, Balance or Intelligence modes. Cursor Router is launching for Teams and Enterprise.

Best use cases

  • Feature work: “Build a dashboard for our research findings with interactive charts” and review the agent’s branch.
  • Refactoring: rename a core module and update every import across a large repo.
  • Code review: let Cursor review pull requests and flag bugs before teammates look.
  • Learning a codebase: ask Chat how authentication flows through the app.

How to get started

  1. Download Cursor for your OS from cursor.com and sign in.
  2. Import your VS Code settings and extensions if prompted.
  3. Open a project and try Tab completions as you edit.
  4. Ask Chat to explain a file, then try Agent on a small task.
  5. Add project rules describing conventions and test commands.
  6. Upgrade to Plus or Premium when you hit Free limits.

Tips and tricks

  • Use the autonomy slider: quick edits for small changes, Agent for larger ones.
  • Reference files explicitly in prompts so the agent focuses on the right code.
  • Run tests after every agent change and commit often.
  • Think before switching from a legacy plan, since the move is permanent.

Example agent prompt:

Add affine gap alignment using Gotoh’s algorithm alongside our existing Needleman-Wunsch implementation, update the FASTA parser to handle multi-line sequences, and add unit tests for both.

Pros and cons

👍 Pros

  • Familiar editor with AI deeply integrated
  • Autonomy slider from targeted edits to full agent mode
  • Works beyond the editor: CLI, Slack, GitHub and iOS
  • Low entry price on the new Plus plan
  • Enterprise options with SCIM, audit logs and pooled usage

👎 Cons

  • Pricing changed significantly in 2026, which can confuse existing users
  • Switching from a legacy plan to The X Subscription is permanent
  • Usage tiers are relative ('4x Plus'), so real limits are hard to compare
  • Agent output still requires review

Who should (and shouldn't) use Cursor

✅ A good fit if you…

  • Code daily and want AI autocomplete plus agents in one editor
  • Run teams that want PR reviews and Slack-triggered tasks
  • Already use Grok or X and want one bundled subscription

⛔ Look elsewhere if you…

  • Want to build apps without coding (consider Lovable or Bolt.new)
  • Prefer a terminal-only agent (consider Claude Code)
  • Need a fixed, unlimited plan with no usage tiers

Cursor alternatives

  • Claude Code — Anthropic's agentic coding tool that plans, edits, tests and ships code from your terminal, IDE, Slack or the web. (from $17/mo (Claude Pro, annual; $20 monthly))
  • GitHub Copilot — AI pair programmer with code completion, chat, a cloud coding agent, code review and access to third-party agents. (from $10/user/mo (Pro))

  • Devin Desktop (formerly Windsurf) — Cognition's AI IDE, the successor to Windsurf, with an agent command center for Devin and third-party coding agents. (from $20/mo (Pro))
  • Replit — Build and publish apps by describing them to Replit Agent, all in the browser. (from See replit.com/pricing (price not confirmed))

FAQ

Is Cursor free?

Yes. The Free plan includes Agent, Chat and Tab completions with Cursor models (Grok and Composer) with limited usage.

How much does Cursor cost in 2026?

New customers choose a plan on The X Subscription: Plus $8, Premium $30, Super $100 or Ultra $200 per month, or $80, $300, $1,000 and $2,000 per year. Teams seats cost $30, $100 or $200 per month. Prices exclude tax.

What happened to Cursor Pro?

Pro ($20 per month) is now a legacy plan. Existing subscribers can keep it; its comparable plan on The X Subscription is Premium.

What is The X Subscription?

It's one subscription covering Grok, Cursor and X. Cursor's help center says switching from a legacy Cursor plan is optional, but permanent once you switch, with a prorated refund of the old plan.

Can Cursor run in the terminal or Slack?

Yes. Cursor runs in your terminal via the CLI, collaborates in Slack and reviews pull requests in GitHub, in addition to the desktop editor.

What are Cursor's Cost, Balance and Intelligence modes?

The old Auto mode was split into three modes, Cost, Balance and Intelligence, that trade off price and capability when Cursor picks models for you.
