What n8n is

n8n (pronounced “n-eight-n”) is a workflow automation platform built for technical teams. You connect apps and services on a visual canvas, drop into JavaScript or Python when you need custom logic, and build AI agents that call tools, use MCP servers and act on your data. It’s “fair-code”: you can self-host it on your own infrastructure or use the managed n8n Cloud.

Its big pricing difference: n8n charges per workflow execution—a full run from start to finish—rather than per step or per user, so a 30-step workflow costs the same as a two-step one.

Key features

Visual builder plus code

Drag nodes for triggers, apps and logic, and add code nodes for transformations and custom API calls.

AI agents

Agents, MCP and AI nodes on every plan, plus access to AI models without bringing your own API keys and an AI Assistant to help build workflows.

Self-hosting

Run n8n with Docker or npm for full data control, or let n8n host it.

Collaboration and governance

Shared projects, admin roles, workflow history and insights on Pro and above; external secret stores and SLAs on Enterprise.

Integrations

Every integration is included on all plans.

Best use cases

  • AI agents: a support agent that reads tickets, queries a database and drafts replies.
  • Internal ops: sync HR, finance and CRM systems.
  • Data pipelines: pull, clean and load data on a schedule.
  • DevOps: route alerts and automate incident steps.

How to get started

  1. Start a free Cloud trial at n8n.io, or self-host with Docker.
  2. Pick a template or create a workflow.
  3. Add a trigger (webhook, schedule or app event).
  4. Add nodes, test each step and inspect the data.
  5. Activate it and monitor executions.

Tips and tricks

  • Batch work into fewer executions to stay within limits.
  • Use sub-workflows for reusable logic.
  • Pin test data while building.
  • Add error workflows to catch failures.

Example AI agent brief:

When a new support email arrives, classify it, look up the customer’s plan in Postgres, draft a reply with an AI agent, and post it to Slack for approval.

Pros and cons

👍 Pros

  • Pay per execution, not per step
  • Self-host for full data control
  • Mix visual building with code
  • Strong AI agent and MCP support
  • Unlimited users and workflows on all plans

👎 Cons

  • Steeper learning curve for non-developers
  • Self-hosting requires maintenance
  • Prices shown to us in euros only
  • Business tier is a big jump from Pro

Who should (and shouldn't) use n8n

✅ A good fit if you…

  • Developers and technical ops teams
  • Need self-hosted automations for compliance
  • Build AI agents connected to internal systems

⛔ Look elsewhere if you…

  • Non-technical users wanting the simplest setup (consider Zapier)
  • Need the largest app catalog
  • Don't want to think about executions or hosting

n8n alternatives

  • Zapier — No-code automation across 9,000+ apps, with AI agents, Copilot, MCP, Tables and Forms. (from $19.99/mo billed annually (Professional))
  • Relevance AI — Build an AI workforce of agents for go-to-market and operations work—no code required. (from $19/mo billed annually (Pro))
  • Lindy — AI teammate that plugs into your tools, learns how you work and handles real tasks across inbox, sales, marketing and ops. (from $49.99/mo for 5,000 credits (Team))
  • Manus — General-purpose AI agent that researches, builds websites and slides, and runs scheduled tasks using credits. (from $20/mo for 4,000 credits (Pro))

FAQ

Is n8n free?

n8n offers a self-hosted Community Edition, and its Cloud plans come with a free trial that doesn't require a credit card. Paid Cloud plans start with Starter.

How much does n8n cost?

The pricing page showed us Starter at €20/month, Pro at €50/month and Business at €667/month, each billed annually, with 2.5K, 10K and 40K workflow executions. Enterprise is custom. Prices displayed in euros for our location; check n8n.io/pricing for your currency.

What counts as an execution?

An execution is one full run of a workflow from start to finish, regardless of how many steps it contains. n8n doesn't charge per step or per user.

Can I self-host n8n?

Yes. You can self-host the Community Edition, and the Business plan is self-hosted. Enterprise can be hosted by n8n or self-hosted.

Does n8n support AI agents?

Yes. All plans include agents, MCP and AI nodes, plus Assistant credits (1,600 per month on Starter, up to 9,600 on Pro) and AI models without needing your own API keys.

n8n vs Zapier?

n8n is cheaper for complex workflows and can be self-hosted; Zapier is easier for non-technical users and has more ready-made app connections. See our Zapier review.
