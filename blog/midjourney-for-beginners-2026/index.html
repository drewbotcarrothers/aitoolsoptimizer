Midjourney for Beginners (2026): Your First Plan, Prompt, and Setting

By Andrew · October 24, 2026

Start Midjourney on Basic if you want to learn it, and move to Standard when 3.3 Fast hours are what stop you. There is no free plan. Basic is $10/month, or $96/year. The first session is one prompt, one aspect ratio, and one variation. It is not a tour of every flag, and it is not V8 alpha.

Where you type

Midjourney runs on the web at midjourney.com and in Discord. Beginners should use the web. Discord is the same generator with a chat interface you do not need on day one. You need an account and a plan. There is nothing to install.

Images on Basic and Standard are public. Do not paste a client’s unreleased product, a private photo, or anything you would not put on a gallery. Stealth is Pro and Mega only. If privacy is day-one requirement, start on Pro or do not start.

A first prompt that is enough

Use four parts:

subject + setting + light + aspect ratio

Example you can paste:

A ceramic cup of tea on a wooden table beside a window, overcast daylight, quiet still-life photo, no text —ar 3:2

Then do only this:

  1. Generate once.
  2. Pick the frame that matches the cup count and the crop.
  3. Vary that frame, or change one phrase (“overcast daylight” to “warm lamp light”).
  4. Stop. Do not add five parameters because a cheat sheet listed them.

--ar is the aspect ratio. --raw pushes the result toward a more literal reading of the prompt. Those two are enough for a first week. The general five-part formula used across tools (subject, setting, style, light, composition) is in the image-generator guide. Midjourney will accept that longer prompt. You do not need it to learn the buttons.

Describe light and a medium (“still-life photo,” “watercolor,” “pencil”). Avoid asking for paragraphs of text inside the picture. If the words matter, that is Ideogram, not a longer Midjourney prompt.

Settings to ignore until Basic feels small

Midjourney’s V8 alpha, opened in March 2026, adds a native 2K --hd mode and --q 4. The help center says some of those heavier settings, including --hd, --q 4, style references, and moodboards, run slower in the alpha, and that Relax is not available on V8 yet.

A beginner who turns those on will spend Fast time faster and will not get the unlimited Relax queue they may have bought Standard for. Learn without them. Add a moodboard or a style reference when you need the next image to resemble a set you already like. Personalization improves if you rate images. Rating can also earn GPU time. It is optional.

Video is a second product on the same plan. Basic includes SD. Standard and above add HD. Do not animate the first still. Get one still you would actually use. Short clips from other tools are covered in best AI video generators.

FAQ

Can a beginner use Midjourney for free?

No. Basic at $10/month is the entry plan. Annual billing brings it to $8/month, paid as $96 up front. Free practice belongs on a tool that publishes a free tier.

What does —ar do?

It sets the aspect ratio. --ar 3:2 is a horizontal still. --ar 2:3 is a vertical one. --ar 16:9 is a wide frame. Pick one and keep it while you learn the prompt.

Should beginners use Discord or the website?

Use the website. The generator is the same idea. The website is the shorter path to a prompt box and a plan. Move to Discord later if your team already lives there.
