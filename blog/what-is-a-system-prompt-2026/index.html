What Is a System Prompt? (2026): The Instruction the User Does Not See

By Andrew · October 24, 2026

A system prompt is the instruction that arrives before the user’s message. It tells the model the role, the boundaries, and the format for this product or this agent. You write one when you build a bot or call an API. In a consumer chat app, the vendor writes it, and you write the message underneath.

The words you type are still the job. How to write those words is what prompt engineering is. A system prompt can ask for a shape. It cannot add a fact the model and the attached files do not have.

Custom instructions in a chat product are a system prompt you are allowed to see. They apply across chats until you change them. They are a poor place for a one-off fact. Put the price, the policy, or the notes in the user message, or in a file the product can read. How much fits is the context window.

A long system prompt spends tokens on every call. The meter is what AI tokens are. Adjectives such as “be world-class” add tokens and leave the facts unchanged. A boundary does more: “quote the article, and stop when it ends.”

Asking for a format with no example in the user message is what zero-shot prompting is. Showing the steps you want is what chain-of-thought prompting is. Both can live under a short system prompt. They do not replace it.

FAQ

Is a system prompt the same as a custom instruction?

In a chat app, custom instructions are the part of the system prompt the product lets you edit. The vendor still sends its own rules around them. In an API, the system field is yours, inside the provider’s usage policy.

Can a system prompt stop hallucinations?

It can require a quote and an abstention when the source is silent. You still read the quote. The failure mode is what an AI hallucination is.

Should every teammate share one system prompt?

Share the rules that are actually company rules: voice, privacy, and what to do when the source is missing. Keep personal preferences in the user message. A shared prompt that tries to cover every department becomes a prompt nobody can debug.

Do I need a paid plan to set one?

Chat products include custom instructions on free tiers, with usage limits. An agent product bills when the agent runs. The system prompt itself is text. The invoice is the inference around it.
