Claude Review (2026): Free, Pro at $20, and One Usage Pool

By Andrew · October 24, 2026

Claude is Anthropic’s assistant for writing, analysis, files, and code, including Claude Code on the same subscription. Pro is $20 a month, or $17 a month if you pay $200 up front. Max is not a different product. It is more of the same usage pool. The limit math is Claude Pro vs Max. This review is what the assistant is for.

Prices and the usage rules were read from Claude’s pricing page on October 24, 2026. List prices exclude tax. App-store prices can differ from the web. We did not count messages or score essays against ChatGPT.

There is no fixed message count. Length, model, and features change how fast the pool drains. Chat on the web, desktop, mobile, and Claude Code draw from the same pool. A person who “hits the limit” is often running a memo and a repository on one tank.

What to use it for

Claude is the assistant to open when the output is a document: a memo, a spec, a careful summary of a file you uploaded. Projects keep that work together. Research, Chrome, and Microsoft 365 connectors are on Pro, on the pricing page. They do not make Claude a search engine. For a question that should come back as links you open, use Perplexity and the research-desk review. For papers, use Consensus or Elicit.

Claude Code is included on Pro and Max. It is not a second subscription, and it is not free capacity. The beginner path is Claude Code for beginners. If the code lives in GitHub and you want completions in the editor you already use, price GitHub Copilot before you buy Max. The editor comparison is Cursor vs Claude Code vs Codex.

Paid plans can turn on usage credits and keep going at API rates after a cap. That is a second bill. Read the meter in Settings, then Usage, before you call Max the only way to finish a Thursday.

Who should pay

Pay for Pro if you write or code with Claude most weeks and Free’s session cap is the thing that stops you. Annual billing is $200, which is $40 less than twelve months at $20. Pay for Max when a measured week of Pro ran out, not because the name says 20×. Skip Claude if your day is Gmail and Drive. That bill is Gemini on Google AI Pro, and the storage is part of the price. Skip a second $20 seat if ChatGPT Plus is already doing the same drafts. One subscription is the point of which AI subscription is worth paying for.

Team is the buy when two or more people need seats and an admin. Enterprise is the buy when the requirement is SSO or an audit log. Do not describe Pro as those controls.

FAQ

Is Claude free?

Yes. Free covers everyday use. Pro is the paid individual plan, at $20 a month or $17 a month billed annually.

Does Pro include Claude Code?

Yes. Claude Code draws from the same usage pool as chat. It does not add a separate allowance.

What is Max for?

More usage: 5× Pro at $100 a month, or 20× Pro at $200 a month, on the five-hour window, with weekly caps still in force. The full limit explanation is the Pro vs Max article.
