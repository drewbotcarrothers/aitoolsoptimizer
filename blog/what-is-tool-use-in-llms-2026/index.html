What Is Tool Use in LLMs? (2026): When the Model Should Look Something Up

By Andrew · October 24, 2026

Tool use is the model deciding it needs a system outside the prompt, then continuing from what that system returns. The system might be web search, a code runner, a calculator, a file, or a calendar. The model proposes the call. Your app, or the vendor’s app, runs it. The answer can be better because it saw today’s page. It can also be worse because it trusted a bad result.

The wire format of that proposal is what function calling is. Read that when you are building the call. Read this when you are deciding whether a product should be allowed to act. A shared plug shape for those tools is what the Model Context Protocol is.

When to turn tool use off

The source is already in the prompt. Search will wander. Paste the paragraph and ask for the edit. A writing pass is ChatGPT vs Claude for writing.

The action moves money or mail. Tool use can draft the message. A person sends it. An agent platform is not a substitute for that click. The log of what ran is what AI observability is.

The corpus is your own files and the web would dilute it. Use a notebook. Gemini Notebook stays on what you upload. That pattern, extended to images and tables, is what multimodal RAG is.

You wanted a format, not a fact. A template is a prompt. Tool use is for when the answer depends on a system. The craft of the prompt is what prompt engineering is.

Each tool call spends tokens or a credit. A loop of calls is why an agent task costs more than a one-line rewrite. If the receipt surprises you, the surprise is the feature working, not a bug in the invoice.

FAQ

Is browsing the same as tool use?

Browsing is one tool. Code execution is another. A product can have one without the other. Read the plan card for the tool you need, not for the word “agent.”

Does the model have to use a tool every time?

No. A good product answers from the prompt when the prompt is enough. Forcing search on a style edit adds a citation you did not need and a chance to import someone else’s sentence.

Can tool use hallucinate?

Yes. It can misread the tool output, or the tool can return the wrong row. The habit is to open the row. A fluent summary of a bad search is still a hallucination.

Is Claude Code “tool use”?

Yes. It is tool use aimed at a repository, and it is included with Claude Pro, not with Free. ChatGPT’s version is Codex, with meaningful access on Plus. Neither one merges code by itself unless you gave it that permission.
