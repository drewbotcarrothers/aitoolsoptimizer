What Is an LLM? (2026): A Plain Definition of a Large Language Model

By Andrew · October 24, 2026

A large language model, an LLM, is a model trained to continue text. You give it a prompt. It produces the next tokens. Chat is that mechanism with a product around it: memory, file upload, tools, and a usage cap. The model does not look up your files unless the product retrieves them or you paste them.

That is why an LLM can draft a clear paragraph and still invent a citation. Fluency is the training goal. Truth is a separate check. When the check is “open the source,” you want retrieval, which is what RAG is.

What an LLM is good at, in this directory

A first draft from notes you supply. Claude and ChatGPT are the usual seats. The writing split is ChatGPT vs Claude for writing. You remain the author of any claim a client will rely on.

A transformation with a format. Turn these bullets into a table. Shorten this to 120 words. Extract dates. The instruction pattern is what prompt engineering is.

Code, when a coding product selects the files. That is still an LLM, with a repository in reach. The editor choice is Cursor vs Claude Code vs Codex.

Answers inside a corpus, when retrieval is real. Perplexity for the public web. Consensus and Elicit for papers. Gemini Notebook for files you upload. The model is still generating the sentences. The sentences are supposed to stay inside the passages.

Mistral Vibe is another assistant with a published seat: Pro is $14.99/month excluding tax, with a free plan. The directory page records that price. It is an option when you want a separate vendor, not a score over the others.

What the acronym does not guarantee

An LLM does not know what changed this morning unless the product searched or you pasted it. It does not have your unshared files. It does not become reliable because the reply is long. A larger context window lets you attach more text. It does not check that text. The limit is what a context window is.

A model that accepts images or audio as well as text is still often called an LLM in product copy, or a multimodal model. The distinction is what multimodal AI is.

Training a further copy on your examples is fine-tuning. Most people using ChatGPT or Claude are not fine-tuning anything. They are prompting a hosted model.

FAQ

Is ChatGPT the same thing as an LLM?

ChatGPT is a product. An LLM is the kind of model behind the reply. The product adds plans, tools, and limits. Plus is $20/month on the directory page checked October 16, 2026.

Is Gemini an LLM?

Gemini is Google’s assistant, built on Google’s models, with a free tier and paid Google AI plans. Plus is $4.99/month. Calling it an LLM describes the text model. The product also generates images and, on paid plans, video.

Do I need to know the model name?

Only when the plan or the API prices models differently. For a chat seat, the plan name (Free, Plus, Pro) changes your allowance. The model picker matters when you are choosing a slower, more expensive mode on purpose.

Can an LLM cite sources?

The model can print a citation-shaped string. A product that retrieves pages can attach real links. Open the link. The failure when the string is invented is what an AI hallucination is.
