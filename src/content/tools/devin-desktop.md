## What Devin Desktop is

Devin Desktop is Cognition's AI development environment. Cognition, the company behind the autonomous software engineer **Devin**, acquired the Windsurf editor and on June 2, 2026 relaunched it as Devin Desktop. The company calls it "a full IDE with an agent manager built in — not the other way around": your editor, extensions, keybindings and language servers still work and remain compatible with Windsurf and VS Code.

What's new is the **Agent Command Center**, now the default view. It shows every local and cloud agent on a Kanban board, so you can dispatch tasks, monitor progress and review results in one place. Companies such as Ramp and NVIDIA are quoted as design partners for multi-agent support.

## Key features

### Agent Command Center
Manage local and cloud agents from a single Kanban view. Third-party agents appear alongside Devin sessions and are reviewed the same way.

### Spaces
Group related sessions and share context between agents, so a research agent's findings can inform a coding agent.

### ACP support
The open Agent Client Protocol lets compatible agents run inside Devin Desktop. At launch: Codex, Claude Agent, OpenCode and others.

### Devin Local
The new primary local agent, rewritten in Rust as the successor to Cascade; up to 30% more token efficient with subagent support. Legacy Cascade remained available through July 1.

### Devin in the cloud
Devin can run in the cloud or on your machine, test in its own browser and keep working until a pull request is ready, even with your laptop closed.

## Best use cases

- **Parallel work:** dispatch one agent to fix a bug, another to write tests and a third to update docs, then review all three.
- **Autonomous PRs:** ask Devin to add SAML SSO following existing auth patterns; it tests sign-in in its own browser and opens a PR.
- **Windsurf migration:** keep your existing setup while gaining agent management.
- **Security scans:** have an agent scan a repository and propose fixes.

## How to get started

1. Download Devin Desktop from devin.ai (Windsurf users can import settings).
2. Open a project and try Tab completions and inline edits.
3. Start a Devin Local session on a small, well-defined task.
4. Connect other agents you use via ACP.
5. Create a Space for a feature so agents share context.
6. Upgrade to Pro for frontier models and higher quotas.

## Tips and tricks

- **Write tasks like tickets:** goal, constraints, acceptance tests.
- **Keep Spaces focused** on one feature to avoid confusing context.
- **Review each agent's diff** before merging, even when tests pass.
- **Use cloud agents for long jobs** so your machine stays free.

Example task:

> Add SAML single sign-on for enterprise organizations. Follow our existing auth patterns, let admins configure it in organization settings, keep email login working for everyone else, and add tests for enforcement and recovery access.
