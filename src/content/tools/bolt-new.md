## What Bolt.new is

Bolt.new, from StackBlitz, is an AI app builder that runs entirely in your browser. You describe what you want ("a booking site for a yoga studio with a class calendar and Stripe checkout") and Bolt's coding agents generate the project, run it in a live preview and let you keep refining it through chat. When you're ready, **Bolt Cloud** hosts it and provides databases and integrations, so you don't need separate hosting accounts.

Bolt's pitch is speed with less friction: it automatically routes each task to the model it thinks fits best, tests and refactors as it goes, and says it can now handle projects "1,000 times larger than before" thanks to improved context management. Its site lists users at companies including Google, Microsoft, Shopify and Stripe.

## Key features

### Chat-to-app building
Start from a prompt, a template (dashboards, storefronts, portfolios) or your design system. Bolt writes the code, installs dependencies and shows a working preview you can click through.

### Automatic model routing and error fixing
Instead of choosing an AI model yourself, Bolt picks one per task to balance quality and token cost, and automatically tests and iterates to reduce errors.

### Bolt Cloud
Hosting, databases, integrations, custom domains and SEO optimization in one place. Paid plans support up to 1M web requests on the listed Pro tier.

### Collaboration
Teams get a shared workspace, centralized billing and per-member token allotments.

## Best use cases

- **Idea validation:** a founder builds a clickable MVP with sign-up and a dashboard to show investors in an afternoon.
- **Marketing pages:** a growth team spins up campaign landing pages with SEO and hosting built in.
- **Internal tools:** an operations manager builds an inventory tracker instead of waiting on IT.
- **Learning:** a student turns a class project into a working app and reads the generated code to learn.

## How to get started

1. Go to bolt.new and sign up free.
2. Describe your app in one paragraph: users, main screens and key actions.
3. Review the plan and preview; click through every screen.
4. Request changes one at a time ("make the header sticky," "add email login").
5. Connect a database or integration through Bolt Cloud when needed.
6. Publish, then upgrade to Pro for a custom domain and no branding.

## Tips and tricks

- **Be specific up front.** A clear first prompt saves tokens on rework.
- **Make small, focused requests** rather than giant multi-feature prompts.
- **Start from a template** when one is close to your idea.
- **Download or review the code** before handling real customer data.

Example starting prompt:

> Build a web app for a dog-walking business. Pages: home with services and prices, booking form with date and time picker, and an admin page listing bookings. Use a clean, friendly design with a green accent color. Store bookings in a database.
