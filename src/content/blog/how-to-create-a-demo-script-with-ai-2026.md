**A demo script written with AI is the path you will click, in order, with the sentence you will say on each screen and the question you will ask the buyer.** The model can turn your outline into spoken lines. It cannot add a feature that is on the roadmap, a customer logo, or a percent saved. If you cannot click it in the build you will show, it stays out of the script.

## What the script is allowed to contain

| Block | Source | The model may |
|---|---|---|
| Who is on the call | Your calendar | Name them. It may not invent a title |
| The outcome you want | One sentence you wrote | Repeat it. It may not add a second close |
| The click path | Screens you verified this week | Order them. It may not add a menu that does not exist |
| The line on each screen | The claim that screen supports | Shorten it. It may not add a metric |
| The question | What you need to learn | Keep it open. It may not supply the buyer's answer |
| The stop | What you will not show | Honor it, including features that are not shipped |

## FAQ

### How long should a first demo be?

As long as the path you can click without apologizing. A 12-minute path you have run is better than a 30-minute path the model padded. Put the time at the top. Cut steps until the time is true.

### Can AI write the discovery questions?

It can rewrite questions you already use. It should not invent the buyer's pain. Leave a blank where you will listen. A script that answers its own questions is a monologue.

### Should the script include pricing?

Only the price you are allowed to say, copied from the rate card. If pricing is custom, the line is that you will scope it. The model does not invent a range.

### Can the script update itself from the roadmap?

No. A roadmap item is not a click. When the feature ships, a person adds the step and runs it once. Until then the stop-list stays in the Project.
