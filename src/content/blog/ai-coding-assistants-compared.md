## Autocomplete vs agent

Copilot started as smart autocomplete inside your editor. Cursor is an AI-first editor that can plan and edit across many files.

## Tips for better results

1. Give context: open or reference the relevant files.
2. Ask for small, reviewable changes.
3. Always run tests before accepting changes.
